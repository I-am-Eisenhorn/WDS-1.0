# HUMAN_FIRST.md

This project began as a fork. The original work matters, and the people who made it should remain visible in the project record.

For WDS 1.0, human-first means:

- keep credit clear;
- write for readers, not only for tools;
- mark uncertainty plainly;
- avoid promotional language;
- make maintenance easier for the next person.

This does not limit the technical direction of the project.

WDS 1.0 is allowed to become its own Windows 11 + AutoHotkey v2 project.
